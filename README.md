# Electric Vehicle Market Analysis and Business Intelligence Dashboard

## Project Overview
This project analyses electric vehicle specifications
using Python, Pandas, MySQL, Tableau and Flask.

## Technologies Used
- Python
- Pandas
- NumPy
- MySQL
- Tableau
- Flask
- HTML and CSS

## Current Progress
- Project environment setup
- Dataset downloaded
- Dataset loaded using Pandas
- Data inspection

## Project Structure
- data: EV datasets
- database: SQL files
- notebooks: Data analysis
- templates: Flask HTML templates
- static: CSS and other assets
- docs: Project documentation
